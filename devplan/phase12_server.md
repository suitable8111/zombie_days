# 개발 지시서: Zombie Days - 자체 서버 IP 기반 실시간 멀티플레이 구현 (Phase 12)

우리는 고정 IP를 가진 자체 리눅스/윈도우 서버를 보유하고 있어. Itch.io(Pygbag HTML5) 클라이언트와 이 자체 서버가 웹소켓(WebSocket)으로 통신하여 플레이어 간의 위치, 차량 탑승 상태, 생존 일수를 실시간으로 동기화하는 멀티플레이 시스템을 구축하려고 해.

네트워크 과부하를 방지하기 위해 가장 호환성이 좋고 가벼운 `python-socketio` (또는 `websockets`) 라이브러리를 사용할 거야. 클라이언트 코드 수정본과 서버 독립 실행 코드를 모두 작성해 줘.

---

### 1. [Server] 파이썬 기반 멀티플레이 중계 서버 코드 (`server.py`)
- **기술 스택**: Python `FastAPI` + `python-socketio` (비동기 모드 호환)
- **CORS 설정**: itch.io 및 로컬 호스트(`*`)에서 들어오는 웹소켓 접속을 모두 허용하도록 CORS 설정을 완전 개방해 줘.
- **핵심 로직**:
  - 유저 접속 시 (`connect`): 고유 `sid`(세션 ID)를 부여하고 현재 접속 중인 다른 유저들의 리스트를 신규 유저에게 전송.
  - 위치 및 상태 동기화 (`update_position`): 클라이언트가 보내온 좌표(X, Y), 차량 탑승 ID, 생존 일수 데이터를 서버 메모리에 저장하고, 나를 제외한 **다른 모든 접속자에게 브로드캐스트(Broadcast)** 처리.
  - 접속 종료 시 (`disconnect`): 유저 정보를 지우고, 다른 유저들에게 해당 유저가 퇴장했음을 알림(`leave_player`).

### 2. [Client] Pygbag 웹 호환 멀티플레이 클라이언트 최적화
- **라이브러리**: Pygbag 웹 환경에서 튕기지 않고 잘 돌아가는 `python-socketio` 클라이언트 모듈을 사용해 줘.
- **서버 주소 설정**: 코드 최상단에 `SERVER_URL = "ws://보유한_서버_IP:포트번호"` 형태로 주소를 분리해 두고, 로컬 테스트 시 `ws://localhost:포트번호`로 쉽게 바꿀 수 있게 주석 처리해 줘.
- **비동기 네트워크 루프 연동**:
  - 게임의 메인 비동기 루프(`async def main():`) 내부에서 내 위치가 변경될 때마다 서버로 데이터를 보낼 수 있도록, 프레임 레이트와 별개로 **초당 20회(20Hz) 주기의 네트워크 틱 타임**을 만들어 패킷을 전송해 줘.
- **타 유저 렌더링**: 서버로부터 수신한 다른 유저들의 데이터를 `remote_players = {}` 딕셔너리에 관리하고, 내 화면 뷰포트 내에 들어올 때만 화면에 캐릭터와 닉네임/생존일수를 그려줘.

### 3. 로컬 및 자체 서버 구동 가이드 작성
- 서버 실행 방법 (`uvicorn server:app --host 0.0.0.0 --port 8000`) 안내.
- 클라이언트 빌드 및 2개 이상의 브라우저 창을 띄워 로컬에서 멀티플레이를 테스트하는 가이드를 텍스트로 정리해 줘.
