# 개발 지시서: Zombie Days - 대자연 지형 및 동적 환경 시스템 (Phase 10)

우리는 지금까지 도시 구조, 상점가, 탈것(탱크/헬기 등), 생존 일자별 난이도를 성공적으로 구현했어. 
이제 무미건조한 타일 반복에서 벗어나, 플레이어가 탐험할 맛이 나는 거대하고 사실적인 대자연 지형(바다, 강, 울창한 숲, 절벽)을 청크 스트리밍 엔진(`updateChunksAndEntities`)에 동적으로 결합하려고 해.

2D 탑다운 환경에서 자연스러운 지형 변화와 생존의 제약(환경적 장애물)을 부여하기 위해 아래의 핵심 요구사항을 반영하여 기존 코드를 고도화해 줘.

---

### 1. 절차적 해안선 및 바다/강 (Water & Coastline System)
- **물(Water) 타일 및 제약**: 맵의 외곽이나 특정 노이즈 범위에 거대한 '바다'와 월드를 가로지르는 '강' 지형을 생성해 줘. 
  - 플레이어, 좀비, 자동차, 오토바이, 탱크는 물 타일에 진입할 수 없거나 속도가 80% 저하되는 패널티를 받아야 해. (단, 헬기와 비행기는 공중으로 무시하고 비행 가능)
- **동적 파도 연출 (Wave Animation)**: 바다와 육지가 만나는 해안선 타일에는 주기적으로 하얀색 거품 파도가 밀려왔다 밀려가는 캔버스 애니메이션 효과(`ctx.fillRect` 또는 알파값 조절)를 주어 살아있는 느낌을 줘.

### 2. 고도 차이를 만드는 절벽 및 고지대 (Cliff & Elevation)
- **절벽(Cliff) 오브젝트**: 맵 곳곳에 통과할 수 없는 '벽' 판정의 바위 절벽 지형을 길게 배치해 줘.
- **지술적 통로 유도**: 절벽은 플레이어의 도보나 차량 이동을 완전히 가로막으므로, 특정 '협곡'이나 '계단' 오브젝트를 통해서만 고지대로 올라갈 수 있게 설계하여 오픈월드 탐험의 경로를 다채롭게 만들어 줘. (헬기는 절벽 고도 무시 가능)

### 3. 시야를 가리는 울창한 숲과 수풀 (Dense Forest & Fog of War)
- **다양한 자연물 스폰**: 청크 생성 시 바위, 작은 수풀, 거대한 나무(Tree) 오브젝트를 무작위로 자연스럽게 군집을 이루며 스폰해 줘.
- **숲의 시야 가림 효과 (Forest Canopy)**: 플레이어가 나무가 빽빽한 '숲(Forest)' 구역에 들어가면 화면에 나뭇잎 레이어가 반투명하게 덮이면서, 숲 밖에 있는 좀비나 아이템이 보이지 않는 '시야 차단 효과'를 구현해 줘. 숲 내부로 깊이 들어가야만 숨겨진 자원이나 숨어있던 좀비가 드러나도록 긴장감을 조성해 줘.
- **파괴 가능한 자연물**: 탱크의 포격이나 화염방사기, 혹은 차량 충돌 시 나무와 바위가 부서지며 '목재(Wood)'나 '석재(Stone)' 아이템을 드롭하고, 이를 철물점에 가져가 나사로 교환할 수 있게 연동해 줘.

### 4. 지형별 동적 사운드 연출 (Ambient Sound Web Audio API)
- 플레이어가 바다나 강 근처에 가면 잔잔한 파도 소리 신디사이저 사운드가, 울창한 숲에 들어가면 바람에 나뭇잎이 흔들리는 스산한 효과음이 배경음(Ambient)으로 자연스럽게 블렌딩되도록 Web Audio API 오디오 엔진을 확장해 줘.

### 코딩 시 주의사항
- **청크 성능 유지**: 대량의 나무와 바위 오브젝트가 생성되더라도 기존의 **뷰포트 컬링(Viewport Cutting)** 시스템이 완벽히 적용되어 화면 밖의 자연물은 연산/렌더링에서 제외되어야 해.
- **단일 파일 유지**: CSS, JS, HTML은 여전히 단 하나의 파일 내에서 유기적으로 돌아가야 하며, 기존의 데이터 구조(상점 위치, 차량 물리 등)가 깨지지 않도록 예외 처리를 철저히 해줘.
